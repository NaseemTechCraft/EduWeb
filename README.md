# EduWeb

## Overview

EduWeb is a responsive educational website designed to teach programming and web development concepts through clear examples, interactive content, and accessible study resources. The site aims to help beginners explore HTML, CSS, and JavaScript fundamentals in a user-friendly format.

## Features

- Responsive layout for desktop and mobile devices
- Educational programming content and code examples
- Clean web design with intuitive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

1. Clone the repository.
2. Navigate to the project directory.
3. Install required dependencies.
4. Run the application.

## Usage

Open `Index.html` in a web browser to explore the EduWeb learning site. Use the site to browse programming topics, review code examples, and practice web development concepts on desktop or mobile devices.
